# Linux Admin Journey 🚀

Welcome to my Linux learning repository.  
This repo documents my hands-on practice while studying Linux administration and building real command-line skills step by step.

Instead of just reading theory, I use this repository to **practice commands**, **record results**, and **organize my lessons** in a clear way.

---

## 📌 About This Repository

This project is my personal Linux study lab.  
Each lesson folder contains practical work such as:

- notes
- screenshots
- command outputs
- small exercises
- proof of completion

My goal is to build a strong foundation in Linux by learning through repetition, testing, and documentation.

---

## 🧠 How I Learn

My learning style in this repo is simple:

1. Study the concept
2. Try the command manually
3. Verify the output
4. Take screenshots
5. Write clean notes
6. Upload everything to GitHub

This helps me keep a record of what I practiced and track my progress over time.
